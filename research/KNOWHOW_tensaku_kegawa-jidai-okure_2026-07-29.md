# 添削会 2026-07-29｜対象：毛皮コート 時代遅れ（kegawa-coat-jidai-okure）

添削者：リベ大 ブログ添削会 主催者（2026-07-23 / 07-28 と同一）
当時の順位：狙いKWで約19位

## 1. リード文（順番が逆・全部やり直し）

**現状の並び**：共感リスト3つ → 「こんにちは」挨拶 → この記事では〜を解説します → 結論 → もう一度「この記事では」

**指摘**
- 「こんにちは」挨拶＋自己紹介は**不要**。インフルエンサーでもないので読ませても無駄。
- **正しい順番**：
  1. 共感（こういうことでお悩みではないですか）
  2. **結論**（まず結論言いますね）
  3. 権威性＋予告（こんな実績の私が A・B・C について現場目線で徹底解説します）
  4. ベネフィット（最後まで読めばこんな悩みが解決します）
- 「この記事で分かること」が**リード文中の文章とBOXで2回**出てくる → 何回言うねん状態。
  - → **BOXは記事の一番上（リード文の前）に置く**。読者はまずそこを見て「知りたいことが書いてある記事だ」と判断する。

**装飾**
- リードが**黒太字だけ**でどこが大事か目立たない → スルーされる。
- **太字＋黄色マーカー（or 下線）**を必ず入れる。記事全体を流し読みしたとき目が止まらないのが最大の損失。

**筆者アイコン画像（動物イラスト）**
- 個人的には**不要**。最近載せている人はいない。どうしても載せたいなら可。
- 記事下部の筆者情報（経歴）自体は残してよい。

## 2. 見出し構成（最大の指摘）

### ① 狙ったKWの答えを一番上に
- 現状、KWの答えになっているのは**8番目のH2**（「時代遅れ」は誤解——今が売り時の理由）。
- **8番目まで読む人は10人中3〜4人**。ここを**一番最初のH2に持ってくる**。
- 「まずこうですよ、だから安心してね」→ その後に他の話。
- H2にKWがほぼ入っていない。SEOの基本として**タイトル → H2 → H3 の順にGoogleへ伝わる**。

### ② H3を積極的に使う
- 現状：H2が9つあるのにH3が機能しているのは**2つだけ**。しかもその中身は**アフィリリンク**。
- 「5つの選択肢」「3つの理由」「4つのNG要因」と数を出しているのに、**目次でその5つ・3つ・4つが見えない** → 読者にもGoogleにも伝わらない。
- **数を出したら、その数だけH3に分解する。** 分解すると必然的に詳しく丁寧に書くことになる。
- 添削者の実サイト（上位安定）は **H2は最大7個程度、そのほぼ全てにH3がある**（H3なしのH2は1つあるかないか）。
- **たとえ**：ビジネス書でH2の半分以上に小見出しが無い本は無い。あとがきくらい。
- **H4・H5は使わなくてよい。H3まで。**
- H3が1個しかないH2は、**そのH3を外す**（比較表1つだけならH3不要）。
- AIに構成を作らせる時に **「全H2に必ずH3見出しを入れて」と強制指示**する。

## 3. アフィリリンク

- **H3見出しをタップするとアフィリリンクに飛ぶ**構造になっている（4番目・5番目・9番目）。これは**サイト構造的におかしい**。H3から外す。
- リンク直前に**コールトゥアクション文がほぼ無く、いきなりリンクが出てくる**。
  - 「こういうのが欲しい人はこういうサービスがあるから使ってね」を必ず添える。
- 置き方の思想：**読者が離脱しそう／満足しそうな気持ちの増減を読んで、そっと添えるだけ。**
  - 「押してくれ押してくれ」の圧＝売り込み感が出ると嫌われる。

## 4. 画像（最重要・即対応）

- アイキャッチは綺麗なのに、**本文画像が1枚もない → 3秒で離脱したくなる。**
- **H2直下の画像は必須。**「H2下は画像必須」と思ってよい。初期の初期。
- 中身は**そのH2以下（H3含む）の内容を要約した画像**。
  - 関係ないフリー画像はGoogleが嫌う。SEO的にもアウト。
  - Canva か ChatGPT で作る（1分で作れる）。
- **文章を増やすより画像を増やす。** AIで文字数はいくらでも増やせるが読みにくくなるだけ。
- **表も画像化**すると視覚的に見やすくスクロール中に目が止まる。
- たとえ：楽天・Amazonの商品ページ。あれが全部文字だったら絶対に買わない。
- アフィリリンクの上にも画像を。リンク先LPの特徴を**1枚に要約した画像**をChatGPTで作る（**LPのスクショ流用はNG**）。

## 5. 文章（Claude特有の硬さ）

- 「クロードで書きましたか？」と一発で見抜かれた。**Claude独特の硬い文章**で頭に入ってこない。
- **日常会話で使わない言葉を使ってはいけない。**
  - 実例：「〜の構造的変化が背景にあります」← 日常会話で「構造的変化」とは言わない。
  - 難しいカタカナ・横文字も同様。**カタカナは日本語に置き換えられるなら置き換える。**
- **漢字2〜3割／ひらがな7〜8割**が読みやすい比率。現状は漢字が多い。
- **句点で必ず改行**（「。で改行」）。現状されておらず**新聞を読んでいる気分**になる。
  - 改行が無いせいで、9つのH2があるのに**500文字くらいの薄っぺらい記事に見えた**。
- 対策：柔らかい文章を書かせるプロンプトを**何度もテストして作り込む**。硬い文章は読者にストレス＝離脱。

## 6. ジャンル・戦略（Satoshiの本題への回答）

### 「このまま買取ジャンルで続けて大丈夫か」→ **大正解。ただしレッドオーシャン寄り。**
- A8で案件が多い＝**お金が大きく動くジャンル**。広告主が金を出してでも使ってほしい証拠。需要も通年安定。
- 自分の得意（買取8年）と世間の需要が一致している＝**当たりのジャンル**。
- ただし上位はほぼ法人。**「サービス名＋口コミ」で1位を取れれば1記事で月10万超**も狙えるが、そこは激戦。
- **サイトの方向性は合っている。足りないのは「キーワード選定力」と「ライティング力」の2つだけ。**
- 2〜3ヶ月・自力で収益が発生しているならAIの使い方はそこそこ上手い。SEOの基礎を押さえればトントン拍子もあり得る。

### 宿題①の回答：リード文の権威性プロフィール
- **冒頭の「こんにちは」＋自己紹介は不要。**
- **入れるなら「こんな私がこれについて語ります」形式でリード文の後半に。** どちらでもよい。
- **記事下部の筆者情報（経歴）は残してOK。アイコン画像は不要。**

### ★ずらしキーワード（今回いちばん重要な戦略）
- サービス名・商標名でのKW選定は**ラッコキーワードに入れれば誰でも同じ結果が見える** → ドメインパワーでガチンコ勝負になり法人に勝てない。
- **サービス名を使わないが、そのサービスを使いたくなる人が検索するKW**を狙う。
  - 例：英会話アフィリで「ECC 評判」ではなく「外国人彼氏 作りたい」→ まず英語が必要だよね → ECCへ誘導。
- 従来は経験がないと思いつけなかったが、**今はAIエージェント（Codex等）に「このサービス名を使わないが、このサービスを必要としている人が検索しそうなKWを100個」と投げれば60〜70点のものが出る** → 実際に検索して空いているものを書く。
- **お宝KWはラッコキーワードでは絶対に見つからない。**

### ★曖昧検索
- 商品名を知らない人が「首 冷たい やつ」のように探す検索。これもAIエージェントで洗い出せる。
- 商標名＋◯◯が最もCVに近いのは事実だが、ライバルが強い。ずらし・曖昧で回り込む。

### ロングテール
- **ロングテールは後回しでよい。** 10〜200記事書いてサジェストを取り切ってからで十分。
- 高単価ジャンルなので、クリック数が少なくても一撃が大きい。小さいPVの記事を寄せ集めて**網羅性を高めればサイト全体の評価が上がる**。

### 低品質記事の扱い
- **1週間で検索から1クリックも無い記事は下書きに戻す**（削除が嫌なら非公開）。
- Googleは「低品質な記事をサイト内に置くな」というポリシー。
- Search Consoleの**平均掲載順位を良い数字に保つ**意味でも有効。稼いでいるサイトは**平均6〜8位**、記事の大半が5位以内。

### カテゴリ集中
- 大ジャンルは1つでも中のカテゴリが散っているなら、**少しでもアクセスがあるカテゴリ1つに絞って一気に記事を増やす**のが試す価値あり。

### SNS
- **このジャンルはSNSと相性が非常に良い**（お金に困った人が使うサービスだから）。
- ブログ用アカウントを作り、AIエージェント（Codex等）にアカウント設計を手伝わせて**1日1投稿**を1〜2ヶ月試す。**ブログより収益化が早い可能性**。
- 事前に「このサービスを使いたくなる人はどういう人か」のペルソナ調査を深くやる。

### その他
- **リベ大公式ブログの情報は2021年で古い。** 特に**ノウハウ図書館のキーワード選定のやり方は古いので読まない方がよい**。プラグイン以外の基本的な書き方は一部採用可。
- ライティングは**中西さん『Webライティングの教科書』＋無料動画**で学び、学んだルールをAIのライティングルールに落として出力を比較する。
- トップページは作り込まなくてよい。**トップを作り込んでCVが上がったケースはほぼ聞かない。**現状のままでOK。
- AI任せで1から稼げるようになった人は、添削者がリベで3ヶ月見た中で**1人もいない**。出てきた情報を自分の頭で精査する必要がある。
