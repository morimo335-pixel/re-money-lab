H2-1：後悔しやすい3つのケース

<h2>ロレックスを売って後悔しやすい3つのケース</h2>

<div style="background:#FFF8E1;border-left:4px solid #C8923A;padding:15px 20px;margin:20px 0;border-radius:4px;">
<p style="margin:0 0 8px 0;"><strong style="color:#C8923A;">💡 解決策（結論）</strong></p>
<ul style="margin:0;padding-left:1.4em;line-height:1.9;">
<li>✅ 相続した時計なら、査定を申し込む前にご家族へ一声かける</li>
<li>✅ 買い直す可能性が少しでもあるなら、今日は決めない</li>
<li>✅ 1社目の金額は「基準」として受け取り、その場で確定させない</li>
</ul>
</div>

<p>現場にいたころ、売った直後にその場で後悔を口にされる方は、実はあまりいませんでした。出張買取ではご年配の方が多く、話を聞いて納得されたら、その場で決められる方がほとんどです。</p>

<p>それでも後悔が表に出てくる場面はありました。次の3つです。</p>

<h3>1. 相続した時計で、家族の間の確認が済んでいない</h3>

<p>いちばん多いのがこれです。ご本人は納得して売られたのに、あとからご親族が出てきて「そんな金額で手放したのか」となる。時計に限らず、私の担当エリアでは年に2〜3回あるかないか、という頻度でしたが、起きるときは必ずこのかたちでした。</p>

<p>反対に、査定の段階で「兄と相談してから」と話が止まることは、少なからずありました。そういうときは無理に進めず、決定権をお持ちの方に同席していただいてから改めて伺う、という進め方をしていました。手間はかかりますが、あとで揉めるより、ずっといいからです。</p>

<p><strong>次の一手：</strong>相続した時計なら、査定を申し込む前に、相続の話し合いに関わったご家族全員に一声かけておく。それだけで、この後悔はほぼ防げます。</p>

<h3>2. 近いうちに買い戻す可能性がある</h3>

<p>「やっぱり返してほしい」とご連絡をいただくこともありました。その場合は改めて金額を相談することになりますし、条件が合わなければ戻らないこともあります。訪問買取（出張買取）にはクーリング・オフの期間がありますので、期間内であればお返しする対応をしていました。</p>

<p>ただ、期間を過ぎてしまえば、それは通常の買い戻しです。同じ時計が同じ値段で手元に戻ってくるとは限りません。</p>

<p><strong>次の一手：</strong>「3年後に、同じ金額を出してもう一度買うか」を自問してみてください。答えが「買う」なら、今回は見送って手入れをして使い続ける方が、結果的に安く済みます。</p>

<h3>3. 1社だけの査定額で決めてしまう</h3>

<p>1社で決めた方と、何社か回られた方で結果に差が出ることは、確かにありました。ただ、その差を生んでいたのは業者の良し悪しだけではありません。<strong>売る側が相場をどれくらい知っているか</strong>、そして<strong>その時計にどれだけ思い入れがあるか</strong>。このふたつで、粘り方が変わってくるのです。</p>

<p>相場をご存じの方は「この状態ならこのくらいのはず」と話ができます。思い入れのある方は、納得いくまで説明を求められます。結果として、その方たちの手元には条件のいい提示が残りやすい、というだけの話です。</p>

<h2>売る前に確認したい4つのこと</h2>

<div style="background:#FFF8E1;border-left:4px solid #C8923A;padding:15px 20px;margin:20px 0;border-radius:4px;">
<p style="margin:0 0 8px 0;"><strong style="color:#C8923A;">💡 解決策（結論）</strong></p>
<ul style="margin:0;padding-left:1.4em;line-height:1.9;">

<li>✅ 保証書・箱・余りコマを探し、型番を控えておく</li>
<li>✅ 税金とキャンセル期限は、申し込む前に確認する</li>
</ul>

<h3>① 所有権・相続・財産分与</h3>

<p>売れるのは、その時計が自分のものになっている場合だけです。名義といっても時計に登記はありませんから、確認するのは次のような点になります。</p>

<ul>
<li><strong>相続した時計</strong>……遺産分割の話し合いが済んでいるか。誰のものになったか、ご家族の間で共通の認識があるか</li>
<li><strong>離婚に伴う整理</strong>……財産分与の対象になっていないか。話し合いが済んでいるか</li>
<li><strong>配偶者から贈られた時計</strong>……贈られたものか、預かっているものか</li>
</ul>

<p>手続きが済んでいないうちに現金化してしまうと、あとから戻すのが難しくなります。判断に迷うときは、売却より先に、話し合いを済ませてください。</p>

<h3>② 型番・状態・保証書・余りコマ</h3>

<p>査定に出す前に、手元にあるものを一度そろえてみてください。あるかないかで話が変わるのは、次のあたりです。</p>

<ul>
<li><strong>型番</strong>……ベルトを外した本体の側面などに刻まれています。分からなければ、保証書の記載でも確認できます</li>
<li><strong>保証書（ギャランティ）</strong>……購入時に付いてくるカードや冊子</li>
<li><strong>箱・説明書・タグ</strong></li>
<li><strong>余りコマ</strong>……ベルトを短くしたときに外した金属のコマ。小袋に入って箱に残っていることが多いです</li>
<li><strong>修理やオーバーホールの明細</strong>……過去に出していれば</li>
</ul>

<p>探す場所は、たんすの奥、押し入れ、金庫、それから購入時の紙袋です。私の経験では、ご本人が「ない」とおっしゃっていたものが、箱の底や引き出しの奥から出てくることがよくありました。<strong>1点でも多く揃っている方が、話は前に進みやすくなります。</strong></p>

<h3>③ 売却益と税金</h3>

<p>ここは思い込みで判断せず、仕組みだけ押さえておいてください。</p>

<p>個人が生活で使っていた品物を売ったお金は、原則として税金がかかりません（<strong>生活用動産</strong>という扱いです）。ただし例外があり、<strong>1個または1組の値段が30万円を超える貴金属・宝石・書画・骨とう品など</strong>は、この例外から外れ、譲渡所得として申告の対象になる場合があります。</p>

<p>ロレックスがどちらに当たるかは、その時計の性質、金額、持っていた目的、売買の状況などから個別に判断されます。<strong>必ず非課税、あるいは必ず課税、と言い切れるものではありません。</strong></p>

<p>そのうえで、譲渡所得には次のような一般ルールがあります。</p>

<ul>
<li>年間<strong>50万円の特別控除</strong>がある</li>
<li>所有していた期間が<strong>5年を超える</strong>場合は長期譲渡所得となり、課税の対象となる金額が2分の1になる</li>
</ul>

<p>高額な時計を売る予定があり、判断に迷う場合は、売る前に最寄りの税務署か税理士にご相談ください。売ったあとよりも、売る前の方が選べる手が多く残ります。</p>

<h3>④ 査定方法とキャンセルの条件</h3>

<p>査定の受け方は、大きく3つです。</p>

<ul>
<li><strong>店頭</strong>……その場で説明を聞ける。持ち込む手間はかかる</li>
<li><strong>宅配</strong>……送って査定してもらう。自宅から出なくて済む</li>
<li><strong>出張</strong>……自宅に来てもらう。荷物を動かさなくて済む</li>
</ul>

<p>方法ごとに、キャンセルできる条件が違います。ここは申し込む前に必ず確認しておきたいところです。</p>

<p>とくに<strong>出張買取（訪問購入）</strong>は、特定商取引法という法律で、契約書面を受け取った日から<strong>8日間のクーリング・オフ</strong>ができ、その間は時計を引き渡すこと自体を断れる、と定められています。一方で<strong>店頭買取や宅配買取は、原則としてこの制度の対象外</strong>とされています。同じ「買取」でも扱いが違う、ということです。</p>

<h3>同じモデルでも査定額が分かれる4つの理由</h3>

<p>査定の現場で見ているのは、次の4つです。</p>

<ol>
<li><strong>型番</strong>……同じ「サブマリーナ」でも、型番が違えば別の時計として扱われます</li>
<li><strong>状態</strong>……ガラスや文字盤の傷、ベルトの伸び、動きに問題がないか。研磨（けんま。傷を落とす磨き直し）をしているかどうかも見ます</li>
<li><strong>付属品</strong>……保証書・箱・余りコマなどが揃っているか</li>
<li><strong>確認日</strong>……その金額がいつ時点のものか。中古時計の相場は動きます</li>
</ol>

<p>本屋の買い取り窓口に例えると分かりやすいかもしれません。同じ本でも、初版か、帯やカバーが付いているか、いま棚で動いているか。それで買い取り額が変わります。時計も同じで、<strong>「モデル名だけ」では値段は決まりません。</strong></p>

<h3>相場情報を見るときに確認する項目</h3>

<p>買取店のサイトや相場まとめの記事を見るときは、次の4点が書かれているかを見てください。</p>

<ul>
<li>どの<strong>型番</strong>か（モデル名だけでなく、数字の型番まで）</li>
<li>どんな<strong>状態</strong>を前提にした金額か（未使用に近いのか、使用感があるのか）</li>
<li><strong>付属品</strong>が揃っている前提か</li>
<li>その金額を<strong>いつ確認したか</strong>、どこの数字か</li>
</ul>

<p>この4つのどれかが欠けている数字は、参考程度に留めておくのが安全です。<strong>本記事でも、条件と確認日をそろえて提示できる段階になるまで、相場表は掲載していません。</strong></p>

<h3>「買取実績」をそのまま自分の1本に当てはめない</h3>

<p>各社が載せている買取実績は、その1本についての実際の金額です。ただし、その1本がどんな状態で、何が揃っていたかまでは分からないことが多い。同じ型番でも、ご自身の時計が同じ金額になるとは限りません。</p>

<p>結局のところ、いちばん確かな相場は、<strong>ご自身の時計を実際に見てもらって出てきた複数社の数字</strong>です。ネットの数字は「だいたいこのくらいの世界か」を掴むまでにして、そこから先は実物を見てもらった方が早いです。</p>

<h3>保証書がなくても売れますか</h3>

<p>売れます。ただ、確認に時間がかかります。</p>

<p>保証書がない時計を見るときは、見られるところを全部見ます。文字盤、針、ケースの仕上げ、ベルト、刻印。必要であれば裏蓋を開けて中も確認します。<strong>古い時計ほど、裏蓋を開けたときに部品が動いてしまうことがあるので、ここは慎重に扱う必要があります。</strong>ご自身で開けようとするのはおすすめしません。</p>

<p>そのうえで、写真を本部に送って判断を仰ぐ、というのが私のいた会社の流れでした。ですので、保証書がない場合は<strong>その場で即答されないことがある</strong>と思っておいてください。時間がかかっても、それは普通の手順です。</p>

<h3>動かないロレックスでも査定できますか</h3>

<p>できます。ただし減額は避けられません。</p>

<p>止まっている、進む・遅れる、といった状態は、そのまま金額に反映されます。ただ前述のとおり、買い取った側は自社で直さず専門業者やオークションに回すのが一般的でした。ですから<strong>売る前にご自身で修理に出す必要はありません。</strong>まず現状で見てもらってください。</p>

<h3>相続したロレックスを売る前に確認することは</h3>

<p>3つあります。</p>

<ol>
<li><strong>遺産分割の話し合いが済んでいるか</strong>。誰のものになったか、ご家族の間で認識が一致しているか</li>
<li><strong>形見として希望している方がいないか</strong>。売却の前に一声かけておく</li>
<li><strong>いつ取得したものか、いくらで購入されたものか分かるか</strong>。税金の話になったときに必要になります</li>
</ol>

<p>この3つが済んでいれば、あとは通常の売却と同じ手順で進められます。</p>

<h3>税金が心配なときはどうすればいいですか</h3>

<p>売る前に、最寄りの税務署か税理士に確認してください。相談は無料で受け付けています。</p>

<p>前述のとおり、生活で使っていた品物の売却は原則として非課税ですが、1個または1組で30万円を超える貴金属・宝石・書画・骨とう品などは譲渡所得の対象になる場合があります。ロレックスがどちらに当たるかは個別の判断になりますので、<strong>ネットの情報だけで「かからない」と決めてしまわない</strong>ことをおすすめします。</p>

<p>確認するときは、購入時期・購入金額の分かる資料（保証書や領収書）を手元に用意しておくと、話が早く進みます。</p>

<h2>まとめ｜売る前に確認すれば、後悔はほとんど防げる</h2>

<div style="background:#FFF8E1;border-left:4px solid #C8923A;padding:15px 20px;margin:20px 0;border-radius:4px;">
