## 1. s1-h2（H2-1要約）
```
買取店の入口の前で立ち止まる女性（左・小さく）と、店内で穏やかに笑う店員（右・小さく）。中央に大きな結論を3行で。
「買取店は査定だけでOK。」
「断っても費用は0円。」
「10人に2〜3人は査定だけの人。」
3行の下に小さく「店員側は慣れています。」
```
## 2. s8-wariai（割合）
```
人型アイコン10人を横一列に。左の2〜3人だけゴールドで塗り、「査定だけで帰る人」とラベル。残りは濃紺で「売る・相談する人」。
上に見出し「来店10人のうち、査定だけは2〜3人。」　下に一言「店員の体感です。珍しくありません。」
```
## 3. s2-h2（流れ）
```
左→右の横フロー4ステップ。丸数字つき。
①「査定だけお願いします」と言う
②品物を渡して待つ（数分〜10分）
③金額を聞く。今日の相場・内訳・手数料を確認
④「今日は持ち帰って考えます」で帰る
矢印はゴールド。各ステップの下に小さなアイコン（口元の吹き出し／はかり／電卓／出口のドア）。
```
## 4. s9-mibunsho（身分証）
```
左右2分割の比較図。
左：「査定だけ」→ 身分証のカードに大きな「不要」（濃紺）。
右：「売ると決めた」→ 身分証のカードに「必要」（ゴールド）。小さく「古物営業法で本人確認が決まっています。」
上に見出し「身分証がいるのは、売る時だけ。」
```
## 5. s10-kotowaru（断る言葉）
```
大きな吹き出し1つに、この一文だけを大きく。
「ありがとうございます。今日は一度持ち帰って考えます。」
吹き出しの下に小さく「理由は言わなくていい。これで会話は終わります。」　左下に小さく女性の横顔アイコン。
```
## 6. s3-h2（5つの不安）
```
2列の表を図解に。左列「不安」、右列「店側の答え」。5行。
①盗品を疑われない？ ｜ 出どころは全員に聞く決まり
②断ったらしつこくされない？ ｜ 店頭でしつこくする理由がない
③金額を紙でもらえる？ ｜ 口頭が多い。自分でメモする
④何店回っていい？ ｜ 何店でも。ただし同じ日に
⑤質屋と買取店どっち？ ｜ 売るなら買取店。手放さないなら質屋
見出し「査定だけで気になる5つの不安。」
```
## 7. s11-shitsukoi（しつこくされない）
```
カウンター越しに、店員が「もう少し出せます」と1回だけ言う吹き出しと、お客が「今日は持ち帰ります」と返す吹き出し。2往復で終わる様子。
下に一言「言われるのは上限の提示1回だけ。同じ一文で終わります。」
```
## 8. s12-hashigo（同じ日に回る）
```
カレンダー1日の中に店アイコン3つ（A店・B店・C店）が並び、それぞれの下に「金額をメモ」のノートアイコン。
上に見出し「回るなら、同じ日に。」　下に一言「金の相場は毎日動く。日をまたぐと比べられません。」
```
## 9. s4-h2（金額の決まり方）
```
横一列の計算式を図解に。
「今日の金相場」×「重さ」×「店ごとの掛け目」＝「査定額」
「店ごとの掛け目」だけゴールドで囲んで強調し、小さく「ここが店で違う。」
上に見出し「同じ指輪でも、店で金額が違う理由。」
```

下に一言「石が主役なら、宝石に強い店で査定だけ。」
